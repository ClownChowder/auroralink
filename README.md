# AuroraLink

Personal phone preview for Bluetooth Buds status and Wear OS companion setup. Watch installation and the live companion round trip remain pending. Samsung apps and firmware remain separate and are not redistributed.

Download the APK and full corresponding source ZIP from [Releases](https://github.com/ClownChowder/auroralink/releases). Upstream copyright notices, model/audio credits and licenses are retained in the source and app assets. This repository indexes personal preview releases; the automatic GitHub source archives are not the app source. Use the explicitly attached `auroralink-source.zip`.
